# Sistemas de Escritorio JavaFX - UAM

Repositorio académico que integra los módulos de gestión para el sector comercial nicaragüense desarrollados con JavaFX.

## Módulos del Sistema
* **Recepción de Lotes de Café:** Módulo diseñado para cooperativas enfocado en el registro, validación estricta de datos (control de fechas y cantidades), alertas de eliminación y menús contextuales sobre `TableView`.
* **Catálogo de Artesanías:** Aplicación para la organización de productos artesanales que incluye navegación mediante `MenuBar`, accesos rápidos en `ToolBar`, visualización de imágenes y filtrado en tiempo real utilizando eventos de teclado (`KeyEvent`).

## Tecnologías Utilizadas
* Java 
* JavaFX
* Maven
* IntelliJ IDEA
